# Автоматизация графиков отгрузки филиалов (РЦ Черная Грязь)

### Входной файл:
- `График_отгрузки_филиалов_неделя_2.xlsm` (базовый план отгрузок)

### Выходной файл:
- `Недельные графики (готовый).xlsx` (7 листов по дням недели, строго 2 машины в час)

### Установка зависимостей (один раз):
```powershell
pip install -r requirements.txt
```

### Команды запуска:

1. **Просто сформировать Excel-файл:**
   ```powershell
   python generate_schedule.py
   ```

2. **Сформировать Excel и создать ЧЕРНОВИКИ писем в Outlook (для проверки):**
   ```powershell
   python generate_schedule.py --draft
   ```
   *Письма появятся в папке «Черновики» вашего Outlook. Каждое письмо содержит ТОЛЬКО рейсы одного перевозчика.*

3. **Сформировать Excel и сразу ОТПРАВИТЬ письма через Outlook:**
   ```powershell
   python generate_schedule.py --send-outlook
   ```
   *Все письма уйдут на тестовый адрес `n.rozhkov@puls.ru`.*
