# Автоматизация транспортного отдела (РЦ Черная Грязь)

Комплексный инструмент для транспортного отдела ООО «ФК ПУЛЬС»:
1. **Графики отгрузки филиалов:** расчет слотов погрузки, назначение перевозчиков по тарифам и матрице исключений, сохранение недельных графиков и персональная рассылка в Microsoft Outlook.
2. **Заявки перевозчикам:** обработка суточных реестров отгрузок, суммирование одинаковых адресов погрузки без дублирования строк, автоматический расчет количества требуемых машин (по 33 паллета), определение населенного пункта для маршрута, заполнение официального бланка Word (`Шаблон.docx`) и сохранение готовых заявок.

---

### 📁 Корпоративное хранение файлов (сетевой / облачный диск `L:`):
Скрипт автоматически сохраняет и считывает файлы по сетевым путям:
- **Недельные графики:** `L:\ОТДЕЛЫ\ТРАНСПОРТНЫЙ ОТДЕЛ\Рожков\РК недельные графики + заявки\Готовые недельные графики`
- **Заявки перевозчикам:** `L:\ОТДЕЛЫ\ТРАНСПОРТНЫЙ ОТДЕЛ\Рожков\РК недельные графики + заявки\Заявки`
*(В случае отсутствия подключения к диску `L:` скрипт автоматически использует резервную папку на Рабочем столе).*

---

### 🚀 Запуск через локальный Веб-интерфейс:

1. **Установка зависимостей (один раз):**
   ```powershell
   pip install -r requirements.txt
   ```

2. **Запуск веб-сервера:**
   - Либо дважды кликните по файлу `run_server.bat`
   - Либо в терминале:
     ```powershell
     python server.py
     ```
   *(Браузер откроется автоматически по адресу `http://localhost:8000`)*

### 📋 Возможности разделов веб-интерфейса:

#### Раздел 1. «Графики отгрузки филиалов»
- 📥 **Загрузка плана (.xlsm):** распределение по слотам строго 2 машины в час, подсветка рейсов на 40 паллет.
- 📊 **Структура итоговой таблицы графика:**
  - **Колонка A:** ключ вида `=G{row}&I{row}&J{row}` (например: `КазаньТК Сияние33`);
  - **Колонка B:** разделитель;
  - **Колонка C:** `Месяц` (например: `Октябрь`);
  - **Колонка D:** `Дата` погрузки (например: `04.10.2026`);
  - **Колонка E:** `Время погрузки` (например: `09:00:00`);
  - **Колонка F:** день недели (`пн`, `вт`, ..., `вс`);
  - **Колонка G:** `Направление` (город назначения);
  - **Колонка H:** `Номер Машины` (порядковый номер машины в день на направление);
  - **Колонка I:** `Перевозчик`;
  - **Колонка J:** `Кол-во паллет ` (`33` или `40`);
  - **Колонка K:** `Дата доставки` — автоматический точный расчет даты и времени прибытия исходя из времени погрузки, норматива дней/часов в пути и разницы во времени между часовыми поясами (например: погрузка в Казань `04.10.2026 09:00:00` + 1,5 суток пути = `05.10.2026 21:00`);
  - **Колонка L:** `Тариф` в формате `#,#0 ₽`;
  - **Колонки N, O, P:** сводная статистика по перевозчикам (`Перевозчик`, `Рейсы`, `%`).
- 🚚 **Нормативы времени в пути и часовые пояса для расчета даты доставки:**
  - **Брянск:** 8 часов в пути (разница во времени: 0 ч);
  - **Волгоград:** 1,5 суток / 36 часов (разница: 0 ч);
  - **Воронеж:** 1 сутки / 24 часа (разница: 0 ч);
  - **Екатеринбург:** 3 суток / 72 часа (разница: +2 ч);
  - **Иркутск:** 7 суток / 168 часов (разница: +5 ч);
  - **Казань:** 1,5 суток / 36 часов (разница: 0 ч);
  - **Краснодар:** 2 суток / 48 часов (разница: 0 ч);
  - **Красноярск:** 6 суток / 144 часа (разница: +4 ч);
  - **Новосибирск:** 5 суток / 120 часов (разница: +3 ч);
  - **Самара:** 2 суток / 48 часов (разница: +1 ч);
  - **Санкт-Петербург (СПб):** 1 сутки / 24 часа (разница: 0 ч);
  - **Ярославль:** 5 часов (разница: 0 ч);
  - **Хабаровск:** 11,5 суток / 276 часов (разница: +8 ч).
- 🎯 **Правила распределения перевозчиков (согласно `Исключения для алгоритма распределения транспорта.docx`):**
  - **Ярославль:** 1-я машина чередуется по дням недели (Пн, Ср, Пт — ИП Мельник; Вт, Чт — ИП Коршунов). 2-я и последующие машины — всегда ИП Гусманов.
  - **Брянск:** 1-я машина — НОРДЛАЙН; 2-я машина — ТК Сияние; 3-я+ — по рентабельному тарифу.
  - **Казань:** 1-я машина — ТК Сияние; 2-я+ — сбалансированно между НОРДЛАЙН, АО Национальный, ООО Агро-Авто.
  - **Уфа:** 1-я машина — ТК Сияние; 2-я+ — АО Национальный и/или ООО Агро-Авто.
  - **Воронеж:** ТОЛЬКО ТК Сияние (другие перевозчики не назначаются).
  - **Ростов-на-Дону:** основной — ТК Сияние (резерв: 1. АО Национальный, 2. ООО Агро-Авто, 3. Буш-Автопром).
  - **Краснодар:** 1-я — ТК Сияние, 2-я — АО Национальный, 3-я — ООО Буш-Автопром, 4-я — ООО Агро-Авто.
  - **Волгоград:** ТОЛЬКО ТК Сияние.
  - **Самара:** 1-я — ТК Сияние; 2-я и последующие — преимущественно АО Национальный.
  - **Екатеринбург:** 1-я — ТК Сияние; 2-я — АО Национальный; 3-я+ — по рентабельному тарифу.
  - **Новосибирск:** строго между ООО ЕманТрансАвто, ООО Виллайн, ООО ВЕБ ЛОГИСТИКА с равномерным недельным балансом.
  - **Красноярск:** строго между ООО ЕманТрансАвто, ООО Виллайн, ООО ВЕБ ЛОГИСТИКА с равномерным недельным балансом.
  - **Иркутск:** строго между Азимут ТК и ООО ЕманТрансАвто с равномерным недельным балансом.
  - **Хабаровск:** 1-я и 2-я машины в день — Азимут ТК; 3-я и последующие — Авангард.
  - **Санкт-Петербург:** 1-я машина — ТК Сияние; 2-я+ — распределяются между НОРДЛАЙН и АО Национальный.
- 🔄 **Интеграция с диском:** кнопка «Обновить из Excel» подтягивает ручные правки из сетевой папки `Готовые недельные графики`.
- ✉️ **Рассылка через Outlook:** формирование индивидуальных писем (или черновиков) строго с рейсами конкретного подрядчика с указанием даты и времени доставки.

#### Раздел 2. «Заявки перевозчикам»
- 📥 **Загрузка суточного реестра (.xlsx):** файл отгрузок со столбцами:
  *Адрес ссылка, Адрес, Количество паллет, Режим термоперевозки, Дата отгрузки, Перевозчик*.
- 📦 **Суммирование паллет:** объединение строк с одинаковым `Адрес ссылка` у одного перевозчика без дублирования.
- 🚚 **Расчет количества машин:**
  - до 33 паллет = 1 машина;
  - от 34 до 66 паллет = 2 машины;
  - от 67 до 99 паллет = 3 машины (каждые 33 паллета сверху добавляют машину).
- 🗺️ **Определение маршрута:** автоматическое извлечение города/деревни из полного адреса погрузки (например: *Лешково*, *д. Давыдовское*, *г. Химки*, *пгт. Лесной Городок*) и формирование строки: `<город/деревня> – д. Черная Грязь`.
- 📄 **Заполнение Word-шаблона:**
  - **Кому:** `<Перевозчик>`
  - **Дата:** текущая дата
  - **Маршрут:** `<город/деревня> – д. Черная Грязь`
  - **Тип транспортного средства:** `<N> х <кол-во> паллет, РЕФ <режим>` (например: `2 х 57 паллет, РЕФ +15+25`)
  - **Адрес погрузки:** `<Адрес ссылка>, <Адрес>` (полный адрес)
  - **Дата и время погрузки:** `<Дата отгрузки> к 9:00`
  - **Дата и время выгрузки:** `<Дата отгрузки>, по прибытию`
- 💾 **Формат сохранения:** `<Перевозчик> (<Адрес ссылка>) <ДД.ММ>.docx` в сетевую папку `Заявки` на диске `L:`.

### 📇 Базы email-адресов перевозчиков:
В проекте разделены базы контактов для двух функционалов:
- **`contacts_schedules.json`** — email-адреса перевозчиков для раздела **«Графики отгрузки филиалов»**;
- **`contacts_orders.json`** — отдельная база email-адресов для раздела **«Заявки перевозчикам»**.
*(Если для перевозчика email еще не заполнен в файле, система автоматически использует адрес по умолчанию `n.rozhkov@puls.ru`)*

### 💻 Консольный запуск:
- Генерация графиков: `python generate_schedule.py`
- Создание черновиков Outlook: `python generate_schedule.py --draft`
- Генерация заявок: `python generate_orders.py`
