# Автоматизация графиков отгрузки филиалов (РЦ Черная Грязь)

### Входной файл:
- `График_отгрузки_филиалов_неделя_2.xlsm` (базовый план отгрузок)

### Выходной файл:
- `Недельные графики (готовый).xlsx` (7 листов по дням недели с понедельника по воскресенье, строго по 2 машины в час, зеленые строки 40 паллет)

---

### 🚀 Запуск через локальный Веб-интерфейс (как в проекте Advantum):

1. **Установка зависимостей (один раз):**
   ```powershell
   pip install -r requirements.txt
   ```

2. **Запуск веб-сервера:**
   - Либо дважды кликните по файлу `run_server.bat`
   - Либо в терминале:
     ```powershell
     python server.py
     ```
   *(Браузер автоматически откроется по адресу `http://localhost:8000`)*

3. **Возможности веб-интерфейса:**
   - 📥 **Загрузка файла:** перетащите или выберите `График_отгрузки_филиалов_неделя_2.xlsm`.
   - ⚡ **Обработка в один клик:** алгоритм распределит слоты по 2 машины/час и сформирует готовый файл.
   - 📥 **Скачивание:** кнопка скачивания `Недельные графики (готовый).xlsx`.
   - ✉️ **Кнопка «Отправить ВСЕМ перевозчикам»:** формирует письма всем компаниям.
   - 👤 **Кнопка «Выбрать конкретного перевозчика...»:** выпадающий список для отправки только одному выбранному подрядчику.
   - 📝 **Выбор режима:** «Создать черновики в Outlook» (для предварительной проверки перед отправкой) или «Отправить сразу».
   - 🔒 **Конфиденциальность:** каждый перевозчик получает письмо строго со своими машинами и слотами.

---

### Консольный запуск (без веб-интерфейса):

1. **Только сформировать Excel-файл:**
   ```powershell
   python generate_schedule.py
   ```

2. **Сформировать Excel и создать ЧЕРНОВИКИ в Outlook:**
   ```powershell
   python generate_schedule.py --draft
   ```

3. **Сформировать Excel и сразу ОТПРАВИТЬ письма через Outlook:**
   ```powershell
   python generate_schedule.py --send-outlook
   ```
