# Автоматизация графиков отгрузки филиалов (РЦ Черная Грязь)

### Структура проекта:
- `generate_schedule.py` — основной скрипт автоматизации
- `График_отгрузки_филиалов_неделя_2.xlsm` — входящий базовый план отгрузок
- `Филиалы 2026_09_28_04.xlsx` — оперативный файл со временем и назначенными перевозчиками
- `Недельные графики.xlsx` — эталонный шаблон оформления
- `Недельные графики (готовый).xlsx` — итоговый сгенерированный файл с 7 листами по дням недели
- `carriers_contacts.example.json` — пример файла контактов перевозчиков для рассылки

### Быстрый запуск:
```bash
cd ~/Documents/графики
python3 generate_schedule.py
```

### Режимы запуска:
```bash
# Предпросмотр писем для перевозчиков
python3 generate_schedule.py --preview-emails

# Указание другой даты понедельника
python3 generate_schedule.py --date 2026-10-05
```
